# rvtech-hacs

Home Assistant plug-in for RV Tech skylight control.  
This integration works with the original Bluetooth receiver from RV Tech.

# Installation

Pair the Bluetooth device with your Bluetooth adapter.

## Manual
1. Clone the repository to your machine and copy the contents of custom_components/ to your config directory
2. Restart Home Assistant
3. Setup integration via the integration page.

## HACS
1. Add this GITrepository to "Custom repositories" in HACS
2. Restart Home Assistant
3. Setup integration via the integration page.

# rvtech-hacs

Home Assistant plug-in für RV Tech Dachfenster Motorsteuerung.  
Diese Integration arbeitet mit dem original Bluetooth Enpfänger von RV Tech.

# Installation
Koppeln Sie das Bluetooth-Gerät mit Ihrem Bluetooth-Adapter.

## Manuell
1. Klonen Sie das Repository auf Ihren Computer und kopieren Sie den Inhalt von custom_components/ in Ihr Konfigurationsverzeichnis.
2. Starten Sie Home Assistant neu.
3. Richten Sie die Integration über die Integrationsseite ein.

## HACS
1. Fügen Sie dieses Git-Repository in HACS unter „Benutzerdefinierte Repositories“ hinzu.
2. Starten Sie Home Assistant neu.
3. Richten Sie die Integration über die Integrationsseite ein.
